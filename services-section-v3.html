Design rationale — v3 (unified accordion)

Single sectionAll 5 services live in one container — no separate "Other Services" or featured-card split. Hick's LawFive rows visible at once; cognitive load stays manageable because only one is expanded at a time. Common RegionEach service is a clearly bordered row; the active row gets a tonal lift (white over off-white). Miller's LawEach expanded body chunks deliverables into 4 chips and 2 KPIs. Fitts's LawThe whole row trigger (full width × 96px) is the click target, well above WCAG minimums. Jakob's LawDisclosure accordion is a familiar pattern (Linear, Apple, Stripe, Anthropic). Aesthetic-UsabilityItalic Instrument Serif numerals — small when collapsed (28px), 56px when active, 180px in the visual card — give the section editorial rhythm without breaking the Suisse Int'l type system. Von Restorff EffectThe active row breaks the pattern (white surface, brand-blue numeral, rotated arrow) so the user always knows where they are. Serial PositionNumbered 01→05 in your stated order; 01 opens by default to anchor the experience. Keyboard a11yEach trigger is a real <button> with aria-expanded and aria-controls; arrow keys could be wired in if needed.
